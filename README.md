# 🎮 Tic Tac Toe Game Using C

## 📌 About the Project
Tic Tac Toe is a two-player console-based game developed using C programming. Players take turns marking X and O on a 3×3 game board. The first player to get three symbols in a row, column, or diagonal wins.

## ✨ Features
- Attractive welcome screen
- Interactive 3×3 game board
- Two-player mode (X and O)
- Input validation
- Winner detection
- Draw detection
- Scoreboard
- Play again option
- Colored terminal interface

## 🛠️ Technologies Used
- C Programming
- GCC Compiler
- Standard C Library
- ANSI Escape Codes

## ▶️ How to Compile

```bash
gcc -Wall -Wextra tic_tac_toe.c -o tic_tac_toe
```

## 🚀 How to Run

```bash
./tic_tac_toe
```

## 🎯 How to Play
1. Player 1 uses X.
2. Player 2 uses O.
3. Enter a position from 1 to 9.
4. The first player to get three symbols in a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.
